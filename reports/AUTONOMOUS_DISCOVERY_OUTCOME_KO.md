# 자율 논문 주제 탐색 결과와 종료 근거

**논문화할 가치가 검증된 새 주제를 찾지 못했다.** 실제 실험·반례·원전 방법과 두 채팅의 독립 심사·교차검토를 근거로, 현재 자율 탐색을 사용자가 허용한 실패 종료 조건에서 마친다. 이는 과학적 발견 성공이나 가능한 모든 연구질문의 소진을 뜻하지 않는다.

사용자 목표 §4E의 종료 규칙: “다만 더 이상의 유효한 연구질문이 없거나, 자원이 부족하거나, 실험이 계속 식별 불가능해진다면 중단 사유를 명확하게 기록하라.” 현재 사유는 자원 부족이나 정해진 라운드 수가 아니라 **반복된 식별 문제와, 후속 후보에서 신규성·구별 가능한 인과 대비를 함께 확보하지 못한 점**이다.

## CPU 검산 두 가지 — 실제 모델 결과와 별개

### 검증자 선택의 정답 기준

32개 항목의 이진 truth T, 기존 판정 A, 추가 판정 V에 대해 두 분포의 모든 쌍별 결합표(T,A)/(T,V)/(A,V), 각 정확도 .75와 공동오류율 .125가 같도록 만들었다. 전체 결합 패턴은 다르다.

| (T,A,V) | 분포 1 개수 | 분포 2 개수 |
|---|---:|---:|
| 000 | 8 | 10 |
| 001 | 4 | 2 |
| 010 | 4 | 2 |
| 011 | 0 | 2 |
| 111 | 12 | 10 |
| 110 | 0 | 2 |
| 101 | 0 | 2 |
| 100 | 4 | 2 |

추가 판정을 최적으로 사용한 정답률은 각각 **87.5%와 75.0%**다. 따라서 쌍별 오류 중첩만으로 S2의 oracle을 정할 수 없다. 이는 기초적인 고차 확률 반례이며 새 정리·실제 LLM 현상이나 CAVEAT/SPLIT의 선언된 가정에 대한 반증이 아니다. [정확한 CPU 열거](../logs/summary/round8_s2_oracle_audit.json)

### 계산 재사용의 관측 동등성

결과 f(x′)를 저장해 읽는 모형과 원입력 x′를 저장하고 질의마다 f를 재계산하는 모형을 구성했다. reverse/not/parity/first-pair의 **6,144개 합성 관측**에서 답값이 모두 같았다. 둘 다 명시 공유 witness와 duplicate−coincidental 전이 패턴을 만들 수 있다. 전단사 reverse/not의 같은 결과·다른 입력 donor는 존재하지 않는다.

Claude의 같은 입력·다른 표 수정안도 검사했다. 결과 D[x]를 저장하는 모형과 표 D를 저장해 매 질의 D(x)를 계산하는 모형은 **20,736개 관측**에서 같았다. 입력 probe x도 그대로여서 입력 보존만으로 표·연산자 복사를 배제할 수 없다. 다른 입력 f(x₂)를 묻는 추가 관측은 일부 모형을 구분할 수 있지만 원래 열거 범위 밖이며, x 특이 행 정보와 계산 결과 재사용까지 일반적으로 분리한 것은 아니다.

GPT는 마지막 검산에서 답값 비교를 logit 비교로 과장하지 말라고 지적했다. 이를 수용해 원래 답값-only 감사본을 로컬에 보존하고, 두 모형에 동일한 값→4코드 logit/softcap readout을 명시한 가능 구성을 추가했다. 그 구성에서는 logit 벡터도 같고 positive margin 전이까지 양쪽에서 발생한다. **이 head는 합성 구성이지 실제 Gemma head를 측정·복제한 것이 아니다.** 이 반례는 제안의 양성 패턴이 계산 결과 재사용을 유일하게 식별하지 못함을 보인다. 모든 다른 관측으로도 영원히 식별할 수 없다는 주장은 아니다.

Claude는 이 범위를 확인한 뒤 남은 조건부 수정안을 철회했다. 같은 값 donor는 identity donor와 다르며, 같은 값 donor에서 변화가 생겼다고 바로 기술 실패라 할 수 없다. 특정 위치 접근을 막아도 정답이 유지된다고 재계산을 증명한 것도 아니다. 다른 중복 상태가 남을 수 있다. [두 기제·수정안·readout의 CPU 감사](../logs/summary/round8_reuse_identifiability_audit.json)

### S1. 같은 값의 미사용 출처가 금지 trace의 과승인을 유발하는가

- **명제:** 선택된 출처·실행 trace·실제 출력은 고정하고, 사용하지 않은 허용 출처의 값만 같게 만들면 금지 trace의 승인률이 증가하는가?
- **선행과 신규성:** 후보 차이는 값 일치의 무작위 인과 대비다. LLM 자체의 계보 판정은 LLMCAPLENS·CoRe·NeuroTaint가 이미 다룬다. 정확한 같음 대비의 독립 기여는 UNVERIFIED이며 현재 실행 Go가 아니다.
- **이전 실측의 동기:** R7-C에서 최종 사실이 같아도 이력에 따른 logit 흔적이 남았지만 obsolete 답 선택0이었다. 값의 진실성과 사용 허용을 분리하는 다른 명제를 검토할 동기일 뿐이다.
- **제안된 설계:** 새 세계에서 사용 출처 권한×미사용 출처와 값 일치×단순 trace 깊이×응답 코드. 명시한 trace와 피연산자 태그 전파 정책을 생성기로 채점한다. 실제 내부 출처 사용을 추정하지 않는다.
- **대조·지표:** nonce 출처·명시 whitelist·권한/코드/행 위치 교환. 금지−허용의 값 일치 승인 증가 차이와 logit margin을 세계 단위로 분석. 준비도는 값이 다른 별도 사례에서만 ≥.90, code ≥.95로 확인하고 주효과와 gate를 혼합하지 않는다.
- **해석:** 양성은 주어진 trace의 정책 판정에서 값 일치의 영향이다. 실제 내부 정보 흐름의 증거가 아니다. practical SESOI10pp 아래로 CI 상한이면 해당 크기의 과승인 가설 중단, 넓으면 미결정, anchor 실패는 식별불가다.
- **교란·실패:** 정책 존재 기준 대 taint 합집합의 혼동, 이름/거리/코드 편향, trace 읽기 실패, 승인 일반편향, 같은 값에서 실제 경로를 관측했다고 하는 오류. 주효과 셀의 계보 교환 성공을 gate로 쓰면 효과를 사전에 제거할 위험이 있다.
- **예산·난이도:** GPT 검토의 576-forward 상한 초안(384main+128anchor+64technical). 미등록 예산이며 구현·실행0회. 실험 전 configs/의 새 등록과 입력 계약이 필요하다.
- **논문 기여:** R7 때 Hold였으나 이번 독립·교차 심사 뒤 현재 독립 논문과 GPU 투자는 No-Go다. 정확한 중복을 증명한 것이 아니라 구별 가능한 기제 예측과 추가 기여를 확보하지 못했다.

### S2. 개별 정확도보다 오류의 상보성으로 검증자를 선택하는가

- **명제:** 개별 검증자의 정확도·비용을 같게 두고 기존 판단자와 겹치는 오류 구조만 맞바꾸면 모델은 추가 정답 정보를 주는 검증자로 선택을 바꾸는가?
- **선행과 신규성:** 오류 상관 측정과 CAVEAT의 자동 correlation-aware routing은 알려져 있다. 표를 읽는 모델의 의사결정 자체는 다르지만, 이를 독립적인 새 학술 명제로 볼 근거가 부족하다.
- **이전 실측의 동기:** R7-E의 과제별 반응 차이는 보편적 한 변수 예측을 지지하지 않았다. 오류 중첩의 알려진 구조를 모델이 쓸 수 있는가로 옮기는 동기이지 현재 그 능력에 대한 증거는 없다.
- **제안된 설계:** 생성 가능한 이진 정답·판정 이력표에서 검증자 정확도는 같게 고정하고 상보적인 오답 집합을 교환한다. 질의 시점에 알 수 있는 정보와 oracle-optimal 추가 정보량을 먼저 정의한다.
- **대조·지표:** 오류 개수 세기 준비도, 동일 비용, 행/검증자/응답 코드 순열, 독립 오류 대조. 교환 시 oracle-optimal 선택 전환률 및 추가 정보량 대비 regret. 세계 내 반복 조건을 먼저 집계한다.
- **해석:** 양성도 우선 합성 표에서의 의사결정 능력이다. 실제 LLM 검증기 신뢰도 추정이나 일반적인 다중 에이전트 신뢰성 개선으로 확대하지 않는다. 산술 준비도 실패는 선택 능력 부재와 구분한다.
- **교란·실패:** 조건부로 어떤 판정이 주어졌는지에 따라 정보량 정의가 바뀜, 다수결과 가치 함수 혼동, 과거 오류표에서 미래 오류가 알려진다는 과도한 가정, 단순 카운팅의 재명명.
- **예산·난이도:** GPT의 704-forward 초안(512main+128anchor+64technical), 미등록·미실행. CAVEAT 원문 mirror 확인 뒤에도 실제 구현보다 질문 차별화가 먼저다.
- **논문 기여:** R7 때 Hold였으나 oracle 식별 반례와 기존 선택 연구 대조 후 현재 No-Go다. 전체 결합표를 읽는 산술 평가를 넘어서는 새 명제가 필요하다.

### G1. 독립 중복 계산의 자발적 재사용과 오류 공유

- **명제:** 별도 작성된 같은 계산이 우연히 답만 같은 다른 계산보다 첫 계산의 결과 상태를 더 많이 재사용해 오류까지 전달하는가?
- **선행과 신규성:** 계산 정체성에 따른 자연 경로 공유가 차별점 후보다. 일반 prefill note·재사용·transplant·necessity는 Models Take Notes/Hidden APIs가 이미 검사했다.
- **이전 실측의 동기:** R7-B의 과도한 그래프 봉인과 형식 붕괴는 자연 그래프를 유지해야 한다는 동기이며 계산 공유의 증거가 아니다.
- **제안된 설계:** GPT 초안은 u=f(x);v=u / u=f(x);v=f(x) / u=f(x);v=g(y), clean 값은 일치. 첫 계산 끝 두 고정 위치의 자연 donor 교환과 first/second 질의. Claude 수정은 같은x·다른 함수표 donor 및 x probe.
- **대조·지표:** identity sham, 같은 결과 donor, 양방향 값·코드 교환. 1차량은 duplicate−coincidental의 donor-value margin 변화. 명시 공유는 전달 양성 witness다.
- **해석:** 양성도 원입력 또는 표·연산자 정보 복사 후 재계산과 구별되지 않는다. 현재 Positive 판정 패턴 자체가 재사용을 식별하지 못한다. 실제 모델 명제는 NOT_EVALUATED다.
- **교란·실패:** 공유 raw input, 연산자/함수표 복사, 어휘 priming, 고정 전단사에서 불가능한 same-value/different-input donor. 입력 probe 보존은 표 복사를 배제하지 않는다.
- **예산·난이도:** GPT1344-call 초안, Claude 수정 약800-call 초안. operative manifest·정확한 donor/anchor 호출 배분은 동결되지 않았으며 실제 모델 호출0. CPU 두 기제 반례6144관측과 수정안20736관측 비교만 수행.
- **논문 기여:** 현재 관측으로는 새로운 계산 공유/공통 오류 원리를 주장할 수 없다. 두 기제가 다른 결과를 예측하는 새 대비 없이 P0를 실행하지 않는다.

### H1. 취소된 값의 직접 읽기와 후속 상태 오염

- **명제:** 취소 이력의 옛값 logit 흔적은 답 위치의 직접 읽기인가, 후속 상태를 통한 간접 영향인가?
- **선행과 신규성:** 기존 misleading-context copying과 prefill downstream influence를 넘어서는 새 예측이 없다. 취소 이력이라는 대상 차이만으로 독립 기여가 되지 않는다.
- **이전 실측의 동기:** R7-C의 동일 FINAL 상태에서 old-value margin 흔적은 실제다. obsolete 답 선택0을 모든 행동 변화0으로 바꾸지 않는다. top1변경7/512쌍·정답변경6쌍을 보존한다.
- **제안된 설계:** 새16world에서 이력3×knockout4×질의2×code2 초안. 답→취소값, 답 이외 후속→취소값, sham, clean을 비교한다.
- **대조·지표:** 같은 수 sham·직접/간접 path mask. 원 제안의 1−masked_trace/clean_trace 비율은 작은 분모에서 불안정하며 인과 매개 비율이 아니다.
- **해석:** 두 경로는 배타적이지 않고 mask는 표상·attention 재분배·형식에 함께 개입한다. 2×2 절대효과로 바꿔도 수정 그래프 효과이며 새 기제 이론이 생기는 것은 아니다.
- **교란·실패:** 작은 신호 비율, 비특이적 mask, contextualized KV, 지워지지 않은 우회 경로, 원래 관찰을 새 확증으로 취급.
- **예산·난이도:** Claude 약818-call 초안(768+기술약50), 미등록·실제 모델0. 준비도/정확한 donor 및 이력 비교 manifest는 완성되지 않았다.
- **논문 기여:** 알려진 경로의 추가 국소화만으로는 부족해 제안자가 교차검토에서 철회했다. 현재 투자 No-Go이며 실제 효과 부재 판정이 아니다.

### H2. 답 형식 cue의 직접 재독과 운반

- **명제:** 코드 출력 모드는 앞 task cue의 직접 재독에서 오는가, 후속 상태가 운반하는가?
- **선행과 신규성:** General Filter Heads의 eager/lazy 경로 검사나 prefill note를 새 형식 대상에 적용하는 수준이다.
- **이전 실측의 동기:** R7-B의 코드표가 열려 있었어도 봉인 후 full-vocab 코드가 붕괴했다. 자연 실행의 cue 필요성이나 경로를 확인한 것은 아니다.
- **제안된 설계:** 16world×경로mask5×질의2×code2×cue형식2=640 초안. 직접/후속/둘다/clean/sham 비교.
- **대조·지표:** Full-vocabulary code 형식과 restricted 정답을 구분하고 cue의 허용 경로 양성 대조가 필요하다.
- **해석:** 형식 붕괴 원인을 알면 측정 도구는 개선되지만 독립 논문 명제는 확보되지 않는다. 관측된 B 실패의 원인을 소급 단정하지 않는다.
- **교란·실패:** 그래프 변경의 광범위 손상, 지시 cue와 코드표 혼동, 복수 운반 상태, sham의 비특이성.
- **예산·난이도:** 약690-call 초안(640+기술약50), 미등록·실제 모델0. 실행 배정 없음.
- **논문 기여:** 측정 위생·기존 도구 적용으로 현재 독창적 연구 후보에서 제외한다.

## 종료의 의미와 재개 조건

현재 결과는 검증 가능한 의미 뉴런·자연 계산 병목·독창적인 기제 논문의 발견으로 이어지지 않았다. 단일 backbone에서 나온 제한적 양성·음성·미식별 결과와 설계 실패는 재현 가능한 연구 기록으로 남긴다. 이 기록을 논문급 기여로 자동 승격하지 않는다.

새로운 결과가 나올 때까지 기존 층·dose·표현을 반복 탐색하거나, 후보 수를 맞추기 위해 약한 질문을 실행하지 않는다. 현재 데이터와 선행에서 정당화한 후보가 모두 탈락한 지점에서 사용자의 명시적 종료 규칙을 적용했다. 모든 연구 분야나 미래 질문이 소진됐다는 주장이 아니며 GPU/RAM/디스크 부족을 사유로 삼지 않았다.

재개에는 새로 동기화된 명제, 경쟁 기제들이 서로 다른 결과를 예측하는 사전 고정 대비, 선행 방법과 구별되는 기여, 해석 가능한 양성 도구 대조가 필요하다. 이후 새 연구에서는 실제 보이는 세계와 token 입력의 분할 중복을 첫 출력 전에 막아야 한다. 현재 예약 분할을 조용히 교체해 확증으로 사용하지 않는다.
