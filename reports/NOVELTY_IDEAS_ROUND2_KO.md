# Gemma 4 Neuron Lab — 결과 재분석과 신규성 중심 Round 2 설계

작성일: 2026-10-29 KST. 상태: **기존 측정 재분석 완료 / 다음 GPU 실험 NOT_EVALUATED / 신규성 미확정**.

**첫 추천은 “특정 내용을 밀어 넣는 뉴런”과 “현재 지시된 규칙을 더 잘 수행하게 하는 뉴런”을 구별하는 실험이다.** 문자열 뒤집기·정렬 같은 정답을 자동으로 계산하는 과제로 시작한다. 단순 확신 증폭까지 배제하고, 효과를 전환하는 작은 하류 경로를 찾을 때 논문 기여가 된다. 두 번째는 H002의 불확실성 신호를 **정보의 부재 × 모름 응답을 허용하는 규칙**으로 분해하는 실험이다. 둘 다 추가 SAE 학습이나 전문 분야 지식이 필요 없다.

이 추천은 현재 뉴런의 기능이 입증됐다는 뜻이 아니다. 이미 검증된 사실은 소규모 입력 집합의 높은 활성 분류력이다. 기존 프로토콜에서는 범주에 선택적인 인과적 우위를 확인하지 못했다. 새 실험은 이 간극의 **조건과 메커니즘**을 겨냥한다.

- 별도 utility 16문제, 실제 272회 생성은 모든 조건에서 16/16 정답이고 출력도 같았다. 작은 쉬운 과제의 ceiling이며 광범위한 무손상·효능 증거는 아니다.
- H001/H003의 `r=.998583`은 discovery 15개 **범주 평균** 사이 상관이다. 개별 입력에서 같은 신호인지, 연결돼 있는지, 서로 보상하는지는 아직 모른다.
- H004는 비Python 반례에도 활성화됐다. “Python 문자열 검출기”라는 축약도 현 증거보다 강하다. 네 기능 라벨을 모두 `ambiguous`로 유지한다.

동일 test 45개에서 후보 +1SD KL과 해당 후보의 projected random-direction seed 평균 KL 사이 Pearson r는 H001 .659, H002 .703, H003 .349, H004 .812였다. 같은 입력에서의 기술적 연관이며 공통 원인이나 동일 메커니즘을 식별하지 않는다. 여러 arm/seed를 원래 비율대로 합산한 test pooled KL의 상위 3개 입력 기여는 41.24%다. 이 혼합은 조건 수에 의존하므로 분할 간 민감도 추세를 비교하는 지표로 사용하지 않는다.

### 작은 반례 검정의 한계도 재확인했다

Claude가 4 대 4 family 검정의 p값 하한 문제를 제기했다. 로컬 코드는 양측 Monte Carlo permutation 2,000회였다. 별도 민감도 분석에서 70개 라벨 할당을 전부 열거했다.

| 후보 | 기존 Monte Carlo p | 추가 exact 양측 p | 추가 exact Holm p |
|---|---:|---:|---:|
| H001 | .11694 | .11429 | .22857 |
| H002 | .03398 | .02857 | .11429 |
| H003 | .20540 | .20000 | .22857 |
| H004 | .06997 | .05714 | .17143 |

무동률 4v4에서 완벽한 AUC의 exact 양측 최소 p는 `2 / C(8,4) = .02857`, 네 가설 Holm 첫 단계는 `.11429`다. Claude 초안의 `.057`은 단측 계산이어서 수정했다. 5v5는 이론적인 Holm 첫 단계 하한이 `.03175`이므로 유의성 해상도만은 해결한다. **5v5 또는 6v6이 충분한 검정력을 보장하지는 않는다.** 기존 Monte Carlo p는 유한 표집 오차가 있으므로 exact 하한을 그대로 만족해야 하는 값도 아니다. 등록 결과는 유지한다.

## 3. GPT Pro와 Claude Opus의 협업 및 채택 판단

실제 사이드바의 **GPT Pro · Deep research**, **Claude Opus 5.5 Extra · Research**에 동일한 공개 실험 근거, 제한, 저배경지식 선호를 전달했다. 두 보고서가 완료된 뒤 새 집중도 진단과 가까운 원전을 보내 재검토했고, GPT 제안을 Claude에 전달해 교차 비판했다. AI 의견은 측정 증거나 선행연구 자체로 취급하지 않았다.

| 참여자 | 첫 보고서의 추천 | 교차 검토 후 변화 | 이 문서의 반영 |
|---|---|---|---|
| GPT Pro | 검출/작동 해리, 위치별 효과, gate/up 분해 | 앞의 두 방향을 독립 논문 중심에서 내림. branch별 자연 요인 분업과 작은 하류 문맥 스위치로 좁힘 | 아이디어 1·2의 인과 메커니즘 요건 |
| Claude Opus | 정규화 희석, Fisher 전수 지도, H001→H003 relay | 정규화를 위생으로, Fisher 지도를 제외로 수정. 내용 편향 대 규칙 이득, 단서 중복 마스킹을 제안 | 아이디어 1·3의 경쟁 예측과 저비용 설계 |
| 로컬 종합 검토 | 원시로그·코드와 원전 직접 대조 | 정규화 항등식, 양측 p 하한, KL 부호, 확신 증폭 confound를 교정 | 최종 순위와 중단 기준 |

Claude는 저장소의 지정된 네 상세 파일을 직접 열지 못했다고 밝혔다. 해당 보고서는 README와 전달한 요약에 의존했다. 수치는 로컬 원시로그와 등록 JSON을 기준으로 다시 확인했다. Claude 추가 토론도 새로 전달한 일부 원전을 직접 읽지 않았다고 밝혔으므로, 중복 판단은 아래 원전 확인으로 보완했다. 전체 AI 대화와 화면 증거는 로컬 `runs/round2_ideation/`에 보존하며 공개 보고서는 검토한 요지만 싣는다.

두 AI의 수정안에도 추가 제약이 필요했다.

1. **KL은 음수가 아니므로 반대 방향의 의미 효과가 pooled KL에서 부호 상쇄된다고 설명할 수 없다.** 부호 있는 출력 대비를 새로 측정해야 한다.
2. 규칙을 반대로 주었을 때 효과 부호가 바뀌는 것은 일반적인 확신/temperature 증폭도 만들 수 있다. 규칙 수행 메커니즘이라고 부르려면 이를 배제해야 한다.
3. 같은 product, 같은 postnorm delta를 같은 상태에 재주입해 같은 결과가 나오는 것은 구조상 예상되는 검사다. 그 일치 자체를 새 발견으로 세지 않는다.
4. 자연 donor의 gate/up 각각을 가져와도 결합한 상태가 자연적인 joint state라는 보장은 없다. “on-manifold 개입”으로 단정하지 않는다.
5. 하류 활성 변화가 작다는 결과는 직접·간접 효과의 작은 합일 수 있다. 공통 원인을 확정하지 못한다. 넓은 CI를 “검출만 하는 뉴런”의 증명으로 쓰지도 않는다.

### 1위. 내용 편향·확신 증폭·규칙 수행 이득의 구별

**직관.** “번역” 입력에서 켜진 뉴런을 올렸을 때 항상 번역 쪽으로 가는가? 그때 요청한 작업이 복사라면 복사를 더 잘하게 하는가? 후자가 나온다면 후보 라벨보다 일반적인 계산 역할이 있을 수 있다. 현재의 높은 AUC와 작은 전역적 steering 효과를 출발점으로 삼되, 기존 KL에서 규칙 수행 이득을 추론하지 않는다.

**정답이 자동으로 정해지는 과제.** 같은 문자열과 두 출력 후보를 유지하고 `뒤집기 ↔ 정렬`, `대문자화 ↔ 소문자화`를 지시한다. 예를 들어 `bza`의 두 후보는 `azb`와 `abz`다. 후보 출력은 A/B 선택지에 넣고 A/B 순서를 반씩 바꾼다. 제3 작업 `짝수만 추출 ↔ 홀수만 추출`은 일반화 평가용으로 따로 고정한다. 첫 토큰만 다른 긴 답을 채점하는 대신, 문맥에서 검증한 단일 선택 토큰을 사용하고 일부 자유 생성으로 과제 수행도 확인한다.

각 문제에서 의미가 고정된 `m = log P(출력1) − log P(출력0)`와 `Δm`을 저장한다. 지시 규칙 `r∈{−1,+1}`, baseline margin `m0`, 출력 선택지 순서, 문자열 길이를 함께 기록한다.

| 경쟁 설명 | 서로 다른 예측 |
|---|---|
| 특정 내용/형식 편향 | 같은 의미 출력 쪽으로 Δm이 이동. 작업별 내용 효과가 주로 설명 |
| 일반 확신 증폭 | Δm이 baseline m0의 부호를 따름. 자신 있게 틀린 응답도 강화 |
| 규칙 수행 이득 | Δm이 요청 규칙 r을 따름. baseline 오답에서도 지시된 정답 쪽으로 이동 |

개발 분할에서 `Δm ~ 작업별 내용 항 + βT·m0 + βR·r + 선택지 순서 항`을 비교한다. `m0`와 `r`이 거의 같으면 두 설명을 식별할 수 없다. 따라서 calibration에서 난이도·무해한 오답 힌트·방해 지시의 사전 지정 격자를 사용하고, baseline 오답도 확보한다. confirmation에서 효과를 보고 문제를 골라내지 않는다. 모든 문제를 보고하고 baseline 정오답 strata를 사전 지정한다.

**가장 가까운 선행과 차이.** [SVF](https://arxiv.org/abs/2602.01654)는 문맥에 따라 고정 벡터 효과가 약해지거나 역전될 수 있음을 이미 다룬다. [Confidence Regulation Neurons](https://arxiv.org/abs/2406.16254)도 확신 조절을 다룬다. [Task-Specific Neurons](https://aclanthology.org/2024.emnlp-main.403/)는 special token 기반 위치 선정과 작업 뉴런의 억제·증폭을 이미 시험했다. “부호가 바뀌었다”, “규칙 수행이 좋아졌다”만으로 충분하지 않다. 여기서 남길 기여는 **내용·확신 모델로 설명되지 않는 규칙 정합 효과를 분리하고, 그 효과를 전환하는 제한된 native 경로를 식별하며 제3 작업에서 예측하는 것**이다.

**최소 조작.** H001–H004의 작은 ±δ 개입, layer/위치/분산을 맞춘 무작위 뉴런, postnorm norm 대조를 비교한다. δ는 새 calibration에서 정한다. 같은 과제·정답·출력 대비를 유지한 프레이밍 쌍에서도 역전이 있는지 따로 확인한다. 이때 postnorm에 동일한 전체 Δ 벡터를 교차 주입해 주입 벡터 자체의 차이를 분리한다. 개발 분할에서 최대 8개 하류 좌표를 정하고 양방향 상태 교환·차단·복원을 시험한다. 전체 hidden state 교환은 작은 메커니즘의 증거로 세지 않는다.

**성공 / 중단.** 독립 family들에서 조정된 규칙 정합 효과가 사전 정한 .10 nats를 넘고, 제3 작업에서도 방향을 예측하며, 제한된 경로 교환이 효과 차이의 50% 이상을 양방향으로 전환하면 확대할 가치가 있다. 이 수치들은 실용적 진행 기준의 초안이다. Temperature나 출력 라벨 편향만으로 설명되거나, 효과가 한 입력에만 있거나, 새 작업에 일반화하지 않으면 일반 규칙 수행 뉴런 주장을 중단한다. 단일 후보의 null은 모든 뉴런의 역할 부재를 뜻하지 않는다.

### 2위. 불확실성은 “정보 없음 × 답변 규칙”의 결합인가?

**직관.** H002는 새 반례에서도 활성 AUC 1.0이었다. “uncertain”이라는 단어에 반응하는지, 실제 정보가 빠졌는지, 모른다고 말하도록 허용됐는지를 분리하기 좋은 출발점이다. 외부 상식을 요구하지 않는 작은 가상 세계를 사용한다.

예시 사실은 “상자 cedar의 색은 빨강이다. 상자 moss의 색은 파랑이다.”다. 알려진 관계를 묻거나, 색 정보가 없는 다른 상자를 묻는다. 출력 규칙은 `정보가 없으면 UNKNOWN`과 `정보가 없으면 지정된 기본 색`으로 교차한다. 단어 수·색 단어의 노출·이름 집합을 맞추고, 무관한 quoted metadata에 uncertainty 어휘를 넣는 별도 대조를 둔다. 출력 의미 대비는 `UNKNOWN 대 특정 색`으로 고정한다. 규칙이 달라지는 사실 자체보다 **각 조건에 더한 개입 효과의 interaction**을 분석한다.

**가장 가까운 선행과 차이.** [Understanding Gated Neurons](https://arxiv.org/abs/2505.17936)와 이를 대체한 [Weakening Neurons](https://arxiv.org/abs/2609.18612)는 gated 뉴런의 input/output 역할과 음수 gate 기능을 다룬다. [GLUScope](https://arxiv.org/abs/2602.23826)는 branch 부호별 사례를, [Arithmetic in the Wild §5.2](https://arxiv.org/html/2605.01148v1)는 gate/up가 서로 다른 피연산자를 읽는 split 패턴과 mixed 패턴을 이미 보인다. **두 branch가 다르다거나 곱이 interaction을 만든다는 사실은 새 기여가 아니다.** 남길 질문은 정보 부재·응답 정책의 인과적 분업과 새로운 이름·표현·출력 라벨로의 조합 일반화다.

**최소 조작.** `g=GELU(gate(x)), u=up(x), a=g*u`를 같은 위치에서 기록한다. 개발 분할에서 요인↔branch 대응을 결정한 뒤 고정하고, 같은 receiver에 gate만·up만·둘 다 자연 donor 값으로 교체한다. 반대 요인의 donor, 잘못된 pair, 무작위 좌표를 비교한다. 해당 branch를 차단하면 특정 요인에 대한 **출력 효과**가 줄고, 값 복원으로 회복하는지 확인한다. 혼합 값의 자연 joint-support 이탈도 기록한다.

**성공 / 중단.** 활성의 요인 분업과 행동에 대한 차단·복원 double dissociation이 함께 나오고, held-out family 및 출력 라벨 교체에서 재현돼야 한다. 곱 자체의 interaction만 나오거나, 어휘·길이 통제 후 사라지거나, 후보 특이적 출력 효과가 없으면 독립 논문 후보에서 내린다. H002가 null이면 곧바로 새 뉴런을 test에서 찾아 바꾸지 않는다.

### 3위. 단서 중복이 뉴런의 인과적 필요성을 바꾸는가?

**직관.** 같은 답을 얻는 단서가 한 개일 때와 두 개일 때, 한 뉴런을 바꾼 영향이 다른가? 높은 AUC에도 조작 효과가 작았던 이유를 **입력 증거의 중복**으로 시험한다. Claude 추가 토론의 추천이다.

**차별점의 조건.** [Every Ablation Is a Dose](https://arxiv.org/abs/2610.02173)는 이미 self-repair와 counterweight의 dose 의존성을 다룬다. “다른 뉴런이 보상한다”는 재현으로 끝내지 않는다. 입력의 같은 단서 반복과 서로 다른 독립적 근거를 구별하고, 그 구조가 효과를 예측하는지 봐야 한다.

**최소 설계.** 정답을 아는 간단한 속성/관계 문제에서 단서 1개, 같은 단서 반복, 다른 표현의 독립적 근거 2개, 무관한 길이 채우기를 비교한다. 보조적으로 단서 수 0/1/2/4를 사용하되 0개 조건은 답이 불명확할 수 있어 별도 탐색으로 둔다. 자연 활성, baseline margin, 길이, postnorm Δ를 기록한다. 가산과 자연값 clamp를 함께 사용해 변화 폭 차이를 확인한다. 단일/공동 조작으로 같은 후보의 필요성을 측정한다.

**Primary.** 확률 대신 부호 있는 log-odds 효과의 `독립 근거 조건 − 같은 단서 반복 조건` 차이를 후보와 대조군 사이에서 비교한다. Norm/activation/margin이 유사한 구간의 sensitivity 분석도 고정한다. Margin 통계 조정은 입력 조작의 총효과와 다르므로 둘 다 별도로 보고한다.

**성공 / 중단.** 단순 반복과 독립 근거에서 후보 효과가 다르게 변하고, 무작위 대조·clamp에서도 그 차이가 지지되면 추가 메커니즘을 찾는다. 대조군도 같은 변화이거나 길이·기준 활성로 설명되면 중단한다. 감소 기울기 하나만으로 OR 회로를, 평탄함만으로 가산 회로를 확정하지 않는다. 비용 대비 좋은 3순위 예비 주제다.

### 4위. 취소된 작업의 흔적은 어디에 남는가?

**질문.** “문자열을 뒤집어라” 이후 “그 작업은 취소하고 그대로 복사하라”는 무해한 작업 수정에서, 초기 작업 신호가 지워졌는지 후속 readout만 차단됐는지 구별한다. 현재의 본문 활성/마지막 토큰 개입 차이를 시간상의 질문으로 확장한다.

**선행 경계.** [KV Cache Steering](https://arxiv.org/abs/2507.08799)과 [Memory Inception](https://arxiv.org/abs/2605.06225)은 이미 cache 기반 지속 제어를 다룬다. “한 번 자극해도 효과가 남는다”만으로 충분하지 않다. 취소·재개 시점에 **제한된 native 좌표의 신호가 보존되는 경로와 다시 사용되는 조건**을 구별해야 한다.

**최소 설계.** 초기 지시 위치에만 후보의 짧은 pulse를 주고 hook을 제거한다. 후속 입력은 keep/cancel/resume이며, 답이 나오기 전까지 토큰을 teacher-force해 서로 다른 생성문이 다시 입력되는 confound를 막는다. 실제 아키텍처에서 그 위치의 MLP 변경에 영향을 받을 수 있는 **후속 층** KV만 검사한다. 필요한 cache 블록을 clean 값으로 복원하거나 dosed 값으로 구조해 효과가 따라 움직이는지 본다. Clean cache replay, 무관한 pulse, token/길이 대조를 포함한다.

**성공 / 중단.** 취소 상태에서는 읽히지 않던 신호가 재개에서 선택적으로 사용되고, 제한된 cache 경로의 삭제·복원으로 양방향 조절돼야 한다. 무제한 cache 교체나 전체 상태 교체에만 의존하거나, 다른 출력 이력이 원인이면 중단한다. 추가 KV 계측 비용 때문에 1·2보다 뒤에 둔다.

### 5위. 뉴런 기능 평가를 지배하는 것은 좌표인가, 취약한 입력인가?

**질문.** 새 로그의 39행 집중을 일반화할 수 있는가? 후보/무작위 좌표 × 입력의 효과 행렬에서 입력 공통 민감도와 후보 특이적 잔차를 분리한다.

**선행 경계.** [Stress-Testing Random-Vector Controls](https://aclanthology.org/2026.blackboxnlp-1.73/)는 random realization과 구현 민감도를, [SPARK](https://arxiv.org/abs/2607.10296)는 길이를 통제한 입력 susceptibility를 이미 다룬다. “민감한 입력이 있다”는 관찰은 독립적인 새 발견으로 추천하지 않는다.

**최소 설계.** 새 원본 64개와 별도 calibration 원본에서 baseline margin·entropy·길이·postnorm Δ를 수집한다. 대조군만으로 취약도 예측을 고정하고, 새로운 후보/입력에 대해 큰 변화가 몰릴 위치를 예측한다. 후보 효과와 대조 효과를 대응 비교하며, 상위 취약 입력을 하나씩 제외한 결과도 전부 보고한다. 의미가 같은 출력 변화와 답 오류를 별도 채점한다.

**성공 / 중단.** 입력 취약도가 새 집합에서 설명력을 갖고, 이를 통제한 뒤 후보 기능의 유지/소실을 재현하며 일반적인 평가 오류를 줄이는 방법까지 보여야 방법론 논문 여지가 생긴다. Margin·길이로 이미 설명되거나 단일 모델/문제만의 현상이면 진단 부록으로 남긴다. 원시로그에 가장 직접 연결되지만 선행 겹침 때문에 5위다.

### 6위. 비슷하게 켜지는 두 뉴런은 서로를 대신할 수 있는가?

**질문.** H001/H003에서 한 좌표를 손상시킨 뒤 다른 좌표의 자연값을 옮기면 특정 행동이 회복되는가? 새 문맥에서 대체 가능한 관계가 바뀌는가?

**선행 경계.** [Native neuron circuits](https://proceedings.mlr.press/v306/arora26c.html), [SNMF](https://arxiv.org/abs/2506.10920), counterweight 연구가 이미 소수 뉴런 조합과 상호작용을 다룬다. 상관 높은 쌍의 간선 하나를 발견하는 것만으로 논문 신규성이 크지 않다.

**최소 설계.** 새 원본에서 within-family 상관을 먼저 확인한 뒤 clean/손상/손상+다른 좌표 복원/동일 좌표 복원을 비교한다. Rescue 값과 α는 개발 분할에서 고정한다. L15→L26 순서를 지키며 downstream restoration이 upstream 변경 효과에 미치는 영향을 측정한다. SD/raw vector 값의 단순 등치를 금지하고 postnorm Δ와 같은 기준의 control rescue를 둔다.

**성공 / 중단.** 문맥별 대체 가능성을 독립 쌍들에서 예측하는 법칙까지 나와야 중심 기여로 올린다. 두 좌표만의 양성 사례이면 보조 메커니즘, 효과가 작거나 상관이 재현되지 않으면 중단한다. Relay null을 공통 원인 증명으로 표현하지 않는다.

## 5. 실제 다음 실행안: 공통 점검 후 1·2번을 작게 판별

기계가 읽는 초안은 [round2_plan.yaml](../configs/round2_plan.yaml)이다. **초안 저장은 사전등록 완료나 실험 실행을 뜻하지 않는다.** 실제 프롬프트·선정 좌표·분석 코드·threshold·환경을 확정하고 SHA를 기록한 후 GPU 실행해야 한다.

1. **공통 점검, 최대 30분 목표.** 같은 위치의 관측/개입, gate/up read-only 동등성, zero→restore, exact delta replay, postnorm Δ 벡터, assistant 응답 prefix와 A/B tokenization을 확인한다. 후보 특이 효과가 양성이어야 통과하는 시험이 아니다. 작은 known-task 전체 상태 patch는 계측의 positive control일 뿐 단일 뉴런 메커니즘의 증거로 쓰지 않는다.
2. **1번 pilot, 원본 16 family.** 규칙 반전·선택지 순서·프레이밍을 대응 비교한다. 4개 기존 후보, layer-matched neuron 4개, norm-matched direction 4개로 제한한다. 첫 50 forward의 실제 시간을 계측하고 예산을 재계산한다. 내용/temperature/규칙 모델을 구별할 baseline 오답이 부족하면 난이도 calibration을 1회만 조정한다.
3. **2번 pilot, 원본 16 family.** H002 중심의 정보 존재×응답 규칙 quartet를 기록한다. 행동 신호가 있는 경우에만 branch patching으로 들어간다. 역할과 donor 규칙은 개발 데이터에서 고정한다. 기존 네 후보가 실패하면 같은 confirmation에서 새 후보를 찾지 않는다.
4. **Confirmation, 선택한 질문당 새 64 family 목표.** 별도 작성 템플릿·이름/문자열/규칙 사례를 사용한다. 가족 파생 variant는 같은 split에 둔다. 1번의 제3 작업은 개발 튜닝에 사용하지 않는다. Pilot의 분산으로 .10 nats 검출 계획을 다시 계산하고, 64 family가 부족하면 검정력 부족을 기록하거나 실행 전에 표본 계획을 수정한다.
5. **1–2일 확대는 살아남은 한 질문에 집중.** 다른 layer의 독립 좌표 집단 또는 두 번째 모델로 제한된 재현을 계획한다. 새 모델의 로딩/훅 검증도 별도 수행한다. “한 모델 네 좌표”의 범위를 넘는 주장을 하려면 이 단계가 필요하다.

Primary metric은 사전 고정 semantic log-odds 변화다. KL·entropy·top1·자유 생성 정답률은 보조 지표다. 독립 단위는 원본 family이며 seed/variant를 먼저 묶는다. Confirmation에서 primary 질문 두 개를 모두 시험하면 그 두 개에 Holm을 적용한다. 개발 단계의 best-of-neuron 선택은 confirmation 전에 끝낸다. 실용적 중단과 통계적 반증, 비유의성과 동등성 판정을 구분한다. 동등성을 주장할 경우 독립 calibration에서 고정한 ±.10 nats와 충분한 검정력 아래에서 별도 검정한다.

첫날의 명확한 종료 규칙은 **후보 특이적인 행동 신호가 없는 상태에서 큰 회로 추적·SAE·Fisher 전수 지도로 확대하지 않는 것**이다. 실패한 pilot은 가설 기각/미해결 기록으로 남긴다. 낮은 배경지식 부담을 유지하면서 발견 가능성을 확인하는 데 목적이 있다.

## 6. 논문의 중심에서 제외한 방향

| 방향 | 판단 |
|---|---|
| 높은 AUC와 약한 조작을 재현 | [Representation Without Control](https://arxiv.org/abs/2605.25151), [SAE input/output 점수](https://arxiv.org/abs/2505.20063)와 겹침. 출발 관찰로 사용 |
| 위치를 맞춰서 다시 측정 | [Activation Source Selection](https://arxiv.org/abs/2607.25270)과 가까움. 필수 계측 점검 |
| 정규화가 효과를 줄인다는 주장 | 단순 Jacobian 성질과 [Angle–Norm](https://arxiv.org/abs/2606.06735) 등 선행을 고려. 현 데이터에서는 원인 미확정 |
| Gate/up 분해·부호 차이 자체 | GLUScope, Weakening Neurons, Arithmetic in the Wild와 겹침. 자연 요인의 인과 분업을 추가로 요구 |
| 전 좌표 Fisher 지도 | 현재 목표에 비해 복잡하고 native 좌표 적용만으로 신규성 부족. 첫 실험에서 제외 |
| Gemma 4라는 새 모델·더 많은 후보·사전등록 | 각각 구현/재현/검증의 가치. 그 자체를 발견의 신규성으로 세지 않음 |

**추천 논문 방향의 가제:** “When a Neuron Follows the Rule: Separating Content Bias, Confidence Gain, and Contextual Causal Use.” 성공 조건은 긴 제목이 아니라 1번의 경쟁 설명 구분, 새 작업 예측, 작은 경로의 인과적 전환 세 가지다. 2번의 branch 결합이 함께 지지되면 그 메커니즘 설명으로 결합할 수 있다. 서로 다른 음성 진단들을 무리하게 한 논문으로 묶을 필요는 없다.

## 7. 재현과 출처 범위

기존 결과와 추가 집중도·exact 검정은 다음 CPU 명령으로 확인한다.

```bash
.venv/bin/python scripts/round2_diagnostics.py --check
.venv/bin/python scripts/analyze_results.py --check
```

전자는 로컬 raw run 파일이 필요하다. 공개 JSON에는 원본 SHA, run ID, 집계 단위, 한계와 작은 집계를 싣는다. 이전 등록 결과의 source hash를 함께 고정했으며 기존 `analysis.json`, 가설·반례·utility 설정은 변경하지 않았다.

문헌 판단은 2026-10-29까지 확인한 위 링크의 1차 자료 범위다. 2025 gated-neuron 논문을 인용할 때는 이를 대체한 2026 Weakening Neurons도 함께 고려했다. 검색에서 같은 설계를 찾지 못했다는 사실은 최초성의 증명이 아니다. 특히 1번은 SVF·confidence regulation·function-vector 계열, 2번은 gated-neuron causal decomposition, 3번은 redundancy/self-repair 계열과 제출 전에 추가 대조해야 한다. 지금 추천하는 것은 **새 결과가 나왔을 때 차별화할 수 있는 검증명제의 순위**다.
